# クマせんせいの つりきょうしつ 🎣

釣りがはじめての子ども（幼稚園児〜）向けに、釣りの流れと安全のやくそくを
**遊びながら**覚えられるブラウザゲームです。

- 文字はひらがな・カタカナだけで、セリフはすべて**音声で読み上げ**ます（文字が読めなくても遊べます）
- 失敗してもゲームオーバーにならず、クマせんせいがやさしく教えてくれます
- タブレット・スマホのタッチ操作に対応しています

## あそびかた

インストールは不要です。`index.html` をブラウザで開くだけで遊べます。

```bash
# ローカルサーバーで開く場合（どちらか）
python3 -m http.server 8000      # → http://localhost:8000
npx serve .
```

GitHub Pages で公開すれば、URL を開くだけでタブレットからも遊べます。

## ゲームのながれ

| # | ステップ | 子どもがすること | 覚えること |
|---|---------|----------------|-----------|
| 1 | 🏪 つりぐや | 釣り方を選ぶ → 釣具屋の棚をまわって道具を選ぶ → おかいけい | 釣り方ごとに合う道具（下の表） |
| 2 | 🤝 やくそく | 2択クイズ（5問・初回のみ） | 大人といっしょ／走らない／ライフジャケット／はりは大人に／投げる前に後ろを見る |
| 3 | 🪝 じゅんび | エサ・ルアーを指でドラッグして、はり／カゴ／スナップにつける | はりはとがっているので大人とつける |
| 4 | 🎣 なげる | 「うしろをみる」→ メーターで投げる（サビキ・探り釣りは足元に落とす） | 投げる前の安全確認 |
| 5 | 👀 まつ | ウキ（ウキ釣り）やさおさき（その他）を見て「あわせる！」 | つついているだけ（ちょんちょん／ぷるぷる）とアタリの違い |
| 6 | 🔄 まく | 「まく」を連打。魚があばれたら手を止めて待つ | 無理に巻くと糸が切れる |
| 🐟 | つれた！ | 持っている道具に合わせた扱い方 → 逃がす or 持って帰る | 魚にはやさしく触る／食べる分だけ持ち帰る |

### 釣具屋さん

棚は「ロッド・リール → ライン → しかけ → エサ・ルアー → みをまもるもの → あるとべんりなもの」の順。
釣り方に合う道具を選ぶと ◎、合わないと △ と理由・おすすめが出ます。おかいけいで ★（ぴったり度）を確認できます。

| 釣り方 | ロッド・リール | ライン | しかけ | エサ・ルアー | 釣れる魚（★はレア） |
|-------|--------------|-------|-------|------------|------------------|
| ちょいなげ | ちょいなげロッド | ナイロン3号 | てんびん | アオイソメ | キス・ハゼ・カレイ・★マダイ |
| サビキづり | いそざお | ナイロン3号 | サビキ | アミエビ | アジ・イワシ・サバ |
| ウキづり | いそざお | ナイロン2号 | ウキしかけ | オキアミ | メバル・アジ・★クロダイ・★マダイ |
| ルアーづり | ルアーロッド | PEライン | リーダーとスナップ | メタルジグ | カマス・サバ・★スズキ |
| さぐりづり | あなづりロッド | ナイロン3号 | ブラクリ | アオイソメ | カサゴ・メバル・★アイナメ |

- ぴったり度 ★4 → レアな魚も釣れる／★2〜3 → アタリが遅くなる／★0〜1 → いちばん釣れやすい魚だけ
- ライフジャケットと帽子は必須（うきわはNG）
- 便利グッズはゲーム内で効果あり：偏光サングラス（水中の魚が見える）、フィッシュグリップ（とげのある魚を安全に持てる）、プライヤー（はり外し）、クーラーボックス（ないと持ち帰れない）＋氷、水汲みバケツ、タオル、ハサミ

釣った魚は「ずかん」に記録されます（ブラウザの localStorage に保存）。全13種類です。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     見た目・アニメーション
js/audio.js       読み上げ（Web Speech API）と効果音（Web Audio API）
js/data.js        セリフ・クイズ・魚のデータ  ← 内容を変えたいときはここ
js/art.js         クマせんせい・魚・海などの絵（SVG）
js/main.js        シーン切り替え・セリフ表示などの共通処理
js/scenes.js      各シーン（タイトル／どうぐ／やくそく／えさ／つり／つれた／ずかん）
```

ビルドツールや外部ライブラリは使っていません（フォントのみ Google Fonts）。

## 内容のカスタマイズ

- **釣り方・道具を変える**: `js/data.js` の `METHODS`（釣り方とぴったりな道具）/ `SHELVES`（釣具屋の棚）を編集
- **クイズを変える**: `js/data.js` の `SAFETY` を編集
- **魚を増やす**: `js/data.js` の `FISH` に追加（色・模様・大きさ・つれやすさ `weight` を指定すると絵が自動で描かれます）
