# クマせんせいの つりきょうしつ 🎣

釣りがはじめての子ども（幼稚園児〜）向けに、釣りの流れと安全のやくそくを
**遊びながら**覚えられるブラウザゲームです。

- 文字はひらがな・カタカナだけで、セリフはすべて**音声で読み上げ**ます（文字が読めなくても遊べます）
- 失敗してもゲームオーバーにならず、クマせんせいがやさしく教えてくれます
- タブレット・スマホのタッチ操作に対応しています

## あそびかた

インストールは不要です。`index.html` をブラウザで開くだけで遊べます。

```bash
# ローカルサーバーで開く場合（どちらか）
python3 -m http.server 8000      # → http://localhost:8000
npx serve .
```

GitHub Pages で公開すれば、URL を開くだけでタブレットからも遊べます。

## ゲームのながれ

| # | ステップ | 子どもがすること | 覚えること |
|---|---------|----------------|-----------|
| 1 | 🏪 つりぐや | さお・しかけ・エサを1つずつ選ぶ（選ぶと自動で次の棚・レジへ）。まちがっていたら店員さんが教えてくれるので、なおすと自動で出発 | 道具の組み合わせ（下の表） |
| 🚗 | うみへ いどう | 約10秒の移動画面。ランダムで1つ「あんぜんクイズ／ひつようなもの／あるとべんりなもの／つりまめちしき」が出る | 安全・持ち物・釣りの知識 |
| 2 | 🪝 じゅんび | 竿・仕掛け・水汲みのどれか1つ（ランダム）→ エサ付け（下の表）。終わると自動で次へ。一度クリアしたものは「とばす」でスキップできる | 竿・仕掛け・水汲み・エサの準備の手順 |
| 3 | 🎣 なげる | **三人称視点**（後ろから釣り人を見る）。① リールを横から見た絵を**下にスワイプ**してベールを下ろす → ② 画面を**上にスワイプ**して投げる（長さ・速さで距離、左右で方向）。後ろを人が通っているときに投げようとすると、その人がびっくりして投げられない。サビキ・探り釣りは下にスワイプで足元に落とす | 投げる前に後ろを確認する・ベールの使い方 |
| 4 | 👀 しずむ・まつ・あわせる | **手元視点＋ワイプ（海の中）**。仕掛けは狙いのタナ（底）まで自動で沈む → リールの絵を**上にスワイプ**してベールを戻す → ワイプで魚が寄ってきて「つんつん」とつつく（回数は毎回1〜4回のランダム）→「ぱくっ!」と食べた瞬間に画面を上にスワイプ（またはボタン）で合わせる。つんつんの途中で合わせると「はやすぎ!」、ぱくっの後に遅れると「おそい!」で魚が逃げ、次の魚を待つ。すぐ合わせると「ナイス あわせ!」。ポイントを外したら「なげなおす」 | アタリを見きわめて合わせるタイミング |
| 5 | 🔄 まく | リールのハンドルを**指でぐるぐる回して**巻く（速く回すほど糸が張る）。魚が暴れたら**回すのをやめて待つ**（暴れるタイミングと長さはランダム）。暴れている時に巻いたり、糸が赤いまま巻くと**糸が切れて**仕掛けを結び直し。ときどき**バレる** | 暴れたら待つ・無理に巻くと糸が切れる |
| 🥅 | とりこみ | 足元まで来たら「ぬきあげる」か「タモで すくう」。大きい魚を抜き上げると落ちることがある。タモは指でドラッグして魚にかぶせる | 小さい魚は抜き上げ、大きい魚はタモ |
| 🐟 | つれた！ | 魚の大きさ（センチ）と自己ベスト → 扱い方 → 逃がす or 持って帰る。ときどきゴミ（長靴・空き缶・ビニール袋）が釣れる | 魚にはやさしく触る／食べる分だけ持ち帰る／ごみは持ち帰る |

### 釣り方ごとのちがい

| 釣り方 | 投げ方 | ワイプで見えるもの |
|-------|-------|------------------|
| ウキづり | ポイントを狙って投げる | ウキの下のエサと、つつく魚。食べるとウキが沈む |
| ちょいなげ | ポイントを狙って投げる | 砂の底のオモリとエサ |
| ルアー | ポイントを狙って投げる | 群れのタナ（黄色い点線）を泳ぐルアー |
| サビキ | 足元に落とす | 群れのタナのカゴ。ときどきエサが出て魚を呼ぶ |
| さぐりづり | 足元のブロックの穴に落とす | 魚の目が光っている穴に魚がいる。いなければ「となりの あなへ」 |

### 釣り場での準備（ミニゲーム）

竿・仕掛け・水汲みからランダムで1つ、そのあと必ずエサ付けをします。

| ミニゲーム | やること |
|-----------|---------|
| 🎣 さお | 穂先から順に竿を伸ばす → 曲がったガイドをタッチしてリールと同じ向きにそろえる → リールに近いガイドから順に糸を通す → ベールを開く→糸を引き出す→ベールを戻す |
| 🪢 しかけ | クリンチノットの練習：スナップサルカンの環に通す → 5回巻く → すき間に通す → ぬらしてゆっくり締める → 余りを切る → 仕掛けをスナップにつける（ルアーはエサの準備でつける） |
| 🪣 みずくみ | ロープの持ち方（手に巻きつけない）→ バケツを落とす → 「くいっ」と引いて水を入れる → ゆっくりたぐる（急ぐと水がこぼれる） |
| 🪱 エサ | 釣り方で変わる。サビキ：ブロックのアミエビをバケツに入れ、海水を足して混ぜ、コマセカゴに8分目つめる／ちょい投げ・探り：アオイソメ（ゴカイの仲間）をつまんで頭からはりに刺し、たらしを1〜2cm残す／ウキ：オキアミの尾を取り、尾側から刺して背に沿って通す／ルアー：フックのからまりを直し、スナップを開いてジグをつけ、閉じる |

釣ったあとの「もういちど つる」はエサの準備だけをやり直します。

### 釣具屋さん

棚は「ロッド・リール → しかけ → エサ・ルアー」の3つ。選んだ組み合わせはレジで店員さんがチェックします。
しかけを基準にいちばん近い釣り方を判定し、合っていない道具に「なおす」ボタンとおすすめを表示します。
全部合うと、その組み合わせの釣り方で海へ出発できます。

| 釣り方 | ロッド・リール | しかけ | エサ・ルアー | 釣れる魚（★はレア） |
|-------|--------------|-------|------------|------------------|
| ちょいなげ | ちょいなげロッド | てんびん | アオイソメ | キス・ハゼ・カレイ・★マダイ |
| サビキづり | いそざお | サビキ | アミエビ | アジ・イワシ・サバ |
| ウキづり | いそざお | ウキしかけ | オキアミ | メバル・アジ・★クロダイ・★マダイ |
| ルアーづり | ルアーロッド | リーダーとスナップ | メタルジグ | カマス・サバ・★スズキ |
| さぐりづり | あなづりロッド | ブラクリ | アオイソメ | カサゴ・メバル・★アイナメ |

釣った魚は「ずかん」に記録されます（ブラウザの localStorage に保存）。全13種類で、種類ごとの最大サイズとゴミ拾いの数も残ります。
ポイントに近く投げるほどアタリが早く、すぐ合わせるほど大きな魚になりやすくなります。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     見た目・アニメーション
js/audio.js       読み上げ（Web Speech API）と効果音（Web Audio API）
js/data.js        セリフ・クイズ・魚のデータ  ← 内容を変えたいときはここ
js/art.js         クマせんせい・魚・海などの絵（SVG）
js/main.js        シーン切り替え・セリフ表示などの共通処理
js/scenes.js      各シーン（タイトル／つりぐや／レジ／いどう／ずかん）
js/prep.js        釣り場での準備ミニゲーム（さお／しかけ／みずくみ／エサ）
js/fishing.js     つり（三人称でなげる → 手元視点＋ワイプで しずむ・さそう・やりとり）と つれた画面
```

ビルドツールや外部ライブラリは使っていません（フォントのみ Google Fonts）。

## 内容のカスタマイズ

- **釣り方・道具を変える**: `js/data.js` の `METHODS`（釣り方とぴったりな道具）/ `SHELVES`（釣具屋の棚）を編集
- **移動画面の豆知識を変える**: `js/data.js` の `TIPS`（quiz / need / handy / trivia）に追加・編集
- **魚を増やす**: `js/data.js` の `FISH` に追加（色・模様・大きさ・つれやすさ `weight` を指定すると絵が自動で描かれます）
