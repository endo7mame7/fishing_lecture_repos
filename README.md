# クマせんせいの つりきょうしつ 🎣

釣りがはじめての子ども（幼稚園児〜）向けに、釣りの流れと安全のやくそくを
**遊びながら**覚えられるブラウザゲームです。

- 文字はひらがな・カタカナだけで、セリフはすべて**音声で読み上げ**ます（文字が読めなくても遊べます）
- 失敗してもゲームオーバーにならず、クマせんせいがやさしく教えてくれます
- タブレット・スマホのタッチ操作に対応しています

## あそびかた

インストールは不要です。`index.html` をブラウザで開くだけで遊べます。

```bash
# ローカルサーバーで開く場合（どちらか）
python3 -m http.server 8000      # → http://localhost:8000
npx serve .
```

GitHub Pages で公開すれば、URL を開くだけでタブレットからも遊べます。

| 🚗 | うみへ いどう | 約10秒の移動画面。ランダムで1つ「あんぜんクイズ／ひつようなもの／あるとべんりなもの／つりまめちしき」が出る | 安全・持ち物・釣りの知識 |

| 4 | 👀 まつ | ウキ（ウキ釣り）やさおさき（その他）を見て「あわせる！」 | つついているだけ（ちょんちょん／ぷるぷる）とアタリの違い |

### 釣具屋さん

棚は「ロッド・リール → しかけ → エサ・ルアー」の3つ。選んだ組み合わせはレジで店員さんがチェックします。
しかけを基準にいちばん近い釣り方を判定し、合っていない道具に「なおす」ボタンとおすすめを表示します。
全部合うと、その組み合わせの釣り方で海へ出発できます。

| 釣り方 | ロッド・リール | しかけ | エサ・ルアー | 釣れる魚（★はレア） |
|-------|--------------|-------|------------|------------------|
| ちょいなげ | ちょいなげロッド | てんびん | アオイソメ | キス・ハゼ・カレイ・★マダイ |
| サビキづり | いそざお | サビキ | アミエビ | アジ・イワシ・サバ |
| ウキづり | いそざお | ウキしかけ | オキアミ | メバル・アジ・★クロダイ・★マダイ |
| ルアーづり | ルアーロッド | リーダーとスナップ | メタルジグ | カマス・サバ・★スズキ |
| さぐりづり | あなづりロッド | ブラクリ | アオイソメ | カサゴ・メバル・★アイナメ |

釣った魚は「ずかん」に記録されます（ブラウザの localStorage に保存）。全13種類です。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     見た目・アニメーション
js/audio.js       読み上げ（Web Speech API）と効果音（Web Audio API）
js/data.js        セリフ・クイズ・魚のデータ  ← 内容を変えたいときはここ
js/art.js         クマせんせい・魚・海などの絵（SVG）
js/main.js        シーン切り替え・セリフ表示などの共通処理
js/scenes.js      各シーン（タイトル／つりぐや／レジ／いどう／じゅんび／つり／つれた／ずかん）
```

ビルドツールや外部ライブラリは使っていません（フォントのみ Google Fonts）。

## 内容のカスタマイズ

- **釣り方・道具を変える**: `js/data.js` の `METHODS`（釣り方とぴったりな道具）/ `SHELVES`（釣具屋の棚）を編集
- **移動画面の豆知識を変える**: `js/data.js` の `TIPS`（quiz / need / handy / trivia）に追加・編集
- **魚を増やす**: `js/data.js` の `FISH` に追加（色・模様・大きさ・つれやすさ `weight` を指定すると絵が自動で描かれます）
